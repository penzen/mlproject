Machine Learning Regression App

Student Performance Prediction

This app predicts a student's expected math score using demographic, academic, and test preparation information. The prediction is powered by a trained machine learning model and a saved preprocessing pipeline.

Input Data

Gender, ethnicity group, parental education, lunch type, test preparation, reading score, and writing score.

Preprocessing

The app uses the saved preprocessor.pkl file to encode and scale new user input.

Prediction

The trained model.pkl file predicts the final math score from the processed input.
